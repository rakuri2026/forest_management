## Column Optimization for Field Teams

The GPKG export has been streamlined to include ONLY essential columns in field-friendly order.

### Before (16 columns - cluttered for field use)

| # | Column Name | Keep/Remove | Purpose |
|---|-------------|-------------|---------|
| - | fid | Auto | Auto-generated by GPKG |
| 1 | tree_id | ❌ REMOVE | Internal tracking only |
| 2 | species_code | ❌ REMOVE | Redundant with scientific name |
| 3 | species_scientific | ✅ KEEP | Species identification |
| 4 | species_local | ✅ KEEP | Local/Nepali name |
| 5 | species_role | ❌ REMOVE | Not needed in field |
| 6 | height_m | ✅ KEEP | Field measurement |
| 7 | dbh_cm | ✅ KEEP | Field measurement |
| 8 | tree_class | ✅ KEEP | Classification |
| 9 | canopy_height_source | ❌ REMOVE | Technical metadata |
| 10 | forest_type | ❌ REMOVE | Already known |
| 11 | block_name | ✅ KEEP | Location identifier |
| 12 | sample_plot_number | ✅ KEEP | Plot assignment |
| 13 | generated_date | ❌ REMOVE | Metadata only |
| 14 | model_version | ❌ REMOVE | Metadata only |
| 15 | notes | ✅ KEEP | Important disclaimers |

---

### After (8 columns - clean & field-ready)

**Column Order (optimized for field workflow):**

| Order | Column Name | Type | Field Use | Example |
|-------|-------------|------|-----------|---------|
| 1 | block_name | String | Which forest block/compartment | "B1" |
| 2 | sample_plot_number | String | Which sample plot(s) | "1" or "1,3" |
| 3 | species_scientific | String | Scientific name for ID | "Shorea robusta" |
| 4 | species_local | String | Local/Nepali name | "Sal" |
| 5 | dbh_cm | Float | Diameter to verify | 35.2 |
| 6 | height_m | Float | Height to verify | 12.5 |
| 7 | tree_class | Integer | Classification (1-4) | 2 |
| 8 | notes | String | Disclaimer & warnings | "SYNTHETIC DATA..." |
| - | geometry | Point | GPS coordinates (auto) | POINT(85.123 27.456) |

---

## Benefits for Field Teams

✅ **Cleaner interface** - No technical metadata cluttering the view
✅ **Logical order** - Location → Species → Measurements → Notes
✅ **Smaller file size** - 50% fewer columns = faster loading
✅ **Print-friendly** - Fits better on paper/mobile screens
✅ **Focus on verification** - Only shows what field teams need to check

## Example Field Workflow

1. **Open GPKG in QGIS** on mobile device
2. **Navigate to Plot 1** using sample_plot_number filter
3. **See only essential columns:**
   - Block: B1
   - Plot: 1
   - Species: Shorea robusta (Sal)
   - DBH: 35.2 cm
   - Height: 12.5 m
   - Class: 2
4. **Verify trees in field** against synthetic predictions
5. **Update measurements** as needed
6. **Read notes** for disclaimers
