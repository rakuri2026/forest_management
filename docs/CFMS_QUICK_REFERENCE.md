## 🚀 5- Minute Quick Start / 5- मिनेट द्रुत सुरुवात

### Step 1: Draw Your Forest Boundary / चरण १: तपाईंको वन सीमाना कोर्नुहोस्

```
1. Click "+ Add Island" button
   ( + Add Island बटनमा क्लिक गर्नुहोस् )
   
2. Click polygon icon in map toolbar
   ( नक्शा टूलबारमा बहुभुज आइकनमा क्लिक गर्नुहोस् )
   
3. Click map to add corners
   ( कोण थप्न नक्शामा क्लिक गर्नुहोस् )
   
4. Double-click to finish
   ( पूरा गर्न डबल-क्लिक गर्नुहोस् )
```

**For multiple islands:** Repeat steps 1-4 for each separate area.
**धेरै टापुहरूको लागि:** प्रत्येक छुट्टै क्षेत्रको लागि चरण 1-4 दोहोर्याउनुहोस्।

---

### Step 2: Name Your Blocks / चरण २: तपाईंका ब्लकहरूलाई नाम दिनुहोस्

```
Each island = 1 block (automatic)
Each island = 1 block (स्वचालित)

To rename:
Click block name → Type new name → Done
ब्लक नाम परिवर्तन गर्न:
ब्लक नाममा क्लिक गर्नुहोस् → नयाँ नाम टाइप गर्नुहोस् → भयो
```

---

### Step 3: Add Special Areas (Optional) / चरण ३: विशेष क्षेत्रहरू थप्नुहोस् (वैकल्पिक)

```
Categories / श्रेणीहरू:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔴 Protected Zone / संरक्षित क्षेत्र
🟢 Plantation / रोपण
🟡 Pro-Poor / गरिब-उन्मुख
🟣 Religious / धार्मिक
🔵 Biodiversity / जैविक विविधता
🌸 Tourist / पर्यटक
⚫ Private Land / निजी जमिन (बाहिर गरिएको)
```

---

## 🎯 Common Tasks / सामान्य कार्यहरू

| Task / कार्य | How To / कसरी |
|-------------|----------------|
| **Add island** | Click "+ Add Island" then draw |
| **Remove island** | Click trash icon on island |
| **Rename block** | Click block name, type new name |
| **Add protected zone** | Click "Protected" → draw on map |
| **Save work** | Click "Save Draft" button |
| **टापु थप्नु** | "+ Add Island" मा क्लिक → कोर्नुहोस् |
| **टापु हटाउनु** | टापुमा ट्र्यास आइकनमा क्लिक गर्नुहोस् |
| **ब्लकको नाम बदल्नु** | ब्लक नाममा क्लिक → नयाँ नाम टाइप गर्नुहोस् |
| **संरक्षित क्षेत्र थप्नु** | "Protected" मा क्लिक → नक्शामा कोर्नुहोस् |
| **काम बचत गर्नु** | "Save Draft" बटनमा क्लिक गर्नुहोस् |

## ⚠️ Important Tips / महत्वपूर्ण सुझावहरू

```
✅ DO / गर्नुहोस्:
━━━━━━━━━━━━━━━━━━━━━━
• Always click "+ Add Island" before drawing
• Save your work frequently
• Use satellite view for better accuracy
• Name your blocks clearly
• Double-click to finish polygons

❌ DON'T / नगर्नुहोस्:
━━━━━━━━━━━━━━━━━━━━━━━━
• Don't draw outside your forest boundary
• Don't create overlapping polygons
• Don't forget to save before closing
• Don't skip naming your blocks
```

## 🔧 Troubleshooting / समस्या समाधान

| Problem / समस्या | Solution / समाधान |
|-----------------|------------------|
| Can't draw | Click "+ Add Island" first |
| Map not loading | Refresh page / Check internet |
| Save failed | Check if logged in / Try again |
| Lost work | Use "Resume Draft" feature |
| कोर्न सकिएन | पहिले "+ Add Island" मा क्लिक गर्नुहोस् |
| नक्सा लोड भएन | पृष्ठ रिफ्रेस / इन्टरनेट जाँच |
| बचत असफल | लगइन गर्नुभएको छ कि / फेरि प्रयास गर्नुहोस् |
| काम हराएको | "Resume Draft" सुविधा प्रयोग गर्नुहोस् |

## 🎓 Keyboard Shortcuts / कीबोर्ड सर्टकटहरू

```
Ctrl + S  → Save Draft (ड्राफ्ट बचत)
Ctrl + Z  → Undo (पूर्ववत)
Ctrl + Y  → Redo (फेरि गर्नु)
Delete    → Remove selected (चयन गरिएको हटाउनु)
Esc       → Cancel drawing (कोर्न रद्द गर्नु)
```
